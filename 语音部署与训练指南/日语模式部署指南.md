# 日语语音模式部署指南（GPT-SoVITS 日语合成）

## 这是什么

桌宠的「日语语音模式」：**界面/气泡保持中文**，说话时把回复**翻译成日语**，用本地 **GPT-SoVITS v2ProPlus 微调模型**（如苏苏洛音色）合成日语。

> 为什么日语要单独一套引擎？桌宠的 Genie 语音引擎只支持中文/英文文本合成（缺少日语 G2P），日语文本交给它会产生乱码。因此日语走独立的 **GPT-SoVITS 推理服务**（端口 9880），中文仍走 Genie（端口 9881），互不影响。

## 一、准备 GPT-SoVITS v2ProPlus 整合包

1. 获取整合包（含内嵌 Python runtime + 预训练权重），解压到任意目录，例如 `D:\GPT-SoVITS`。
2. 确认环境可用（需要 NVIDIA 显卡，≥4GB 显存）：

   ```bat
   D:\GPT-SoVITS\runtime\python.exe -c "import torch; print(torch.cuda.is_available())"
   ```

   输出 `True` 即可。

## 二、准备音色模型（二选一）

### A. 用目标音色的语音训练（推荐，效果最好）

1. 收集 **30~100 条 3~10 秒干净人声**（无 BGM、无混响），逐条配好**文本**（语音是什么语言，文本就用什么语言，日语用日语文本）。
2. 用套件 WebUI 或脚本完成：数据预处理 → SoVITS 训练 → GPT 训练。
3. 得到两个权重文件：
   - SoVITS：`SoVITS_weights_v2ProPlus\<名字>_e50_s<步数>.pth`
   - GPT：`GPT_weights_v2ProPlus\<名字>-e20.ckpt`

### B. 先用套件预训练模型（快速体验）

- 不训练，直接用整合包自带的预训练权重（音色为默认音色），先把链路跑通，以后再换自己的模型。

## 三、配置桌宠 config.json 的 ttsGsv

打开桌宠的 `config.json`（托盘菜单 →「打开配置 config.json」），找到 `ttsGsv` 段，填入你的路径：

```json
"ttsGsv": {
  "enabled": true,
  "server": "http://127.0.0.1:9880",
  "python": "D:\\GPT-SoVITS\\runtime\\python.exe",
  "serverScript": "D:\\GPT-SoVITS\\api.py",
  "sovitsPath": "D:\\GPT-SoVITS\\SoVITS_weights_v2ProPlus\\sussurro_e50_s1050.pth",
  "gptPath": "D:\\GPT-SoVITS\\GPT_weights_v2ProPlus\\sussurro-v2proplus-e20.ckpt",
  "refAudio": "D:\\ref\\ref_ja.wav",
  "refText": "参考音频里说的日语原文",
  "startTimeout": 240000
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| `python` | 套件内嵌 Python：`<套件目录>\runtime\python.exe` |
| `serverScript` | 套件根目录的 `api.py` |
| `sovitsPath` / `gptPath` | 训练好的 SoVITS / GPT 权重绝对路径 |
| `refAudio` | 3~10 秒干净日语参考音频（最好以句号收尾的完整句，避免合成开头串词） |
| `refText` | 参考音频的**逐字日语原文** |
| `startTimeout` | 服务器模型加载最长等待（毫秒） |

> 路径分隔符用双反斜杠 `\\` 或正斜杠 `/`；中文/空格路径也可以，但确保 JSON 格式正确（逗号、引号完整）。

## 四、开启日语模式并验证

1. 桌宠 设置 → 语音 → 勾选「🗣 日语语音模式」→ 点「💾 保存语音设置」。
2. 发一条消息。首次会说慢一点：桌宠会自动拉起 GPT-SoVITS 服务（模型加载约 1~3 分钟），日志在 `data\tts.log`。
3. 气泡显示中文、**播放日语**，即成功。

## 五、常见问题

- **说话还是中文**：确认①日语语音模式已勾选保存；②`ttsGsv` 路径真实存在；③端口 9880 有服务在听（`netstat -ano | findstr 9880`）。
- **日语开头有参考音频的尾音**：参考音频换一个结尾干净（句号收尾）的句子。
- **听不到/一直卡住**：看 `data\tts.log` 里 `[gsv]` 开头的记录；确认显卡驱动正常、显存足够。
- **日语不可用时**：桌宠会自动回退中文（Genie 音色），不会哑。
- **中文语音不受影响**：Genie 服务（9881）独立运行，与日语服务互不干扰。

## 六、给开发者的接口说明

GPT-SoVITS 服务是标准的 api.py HTTP 接口：

```text
GET http://127.0.0.1:9880/?text=日语文本&text_language=ja   →  返回 wav
GET /change_refer?refer_wav_path=...&prompt_text=...&prompt_language=ja  → 热切换参考音频
```

桌面版已内置「自动拉起 + 健康检查 + 失败回退」，无需手动启动。
