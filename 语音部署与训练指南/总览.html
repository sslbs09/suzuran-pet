🎤 苏苏洛 · 语音部署与训练指南

桌宠默认是「文字气泡」交流，完全不需要语音。想让她开口说话？四种方案从易到难任选一个就行。

先搞懂：语音是怎么走的

桌宠的语音链路（按优先级）：

本地克隆音色（Genie）→ 百炼 CosyVoice → edge-tts → Windows 系统语音

每一层失败会自动落到下一层，所以哪怕什么都不装，只要打开语音开关，至少会有「系统语音」出声。前几层都关掉的话，就直接用系统自带语音，零安装。

方案一：系统自带语音（零配置，推荐先试）

不需要装任何东西
  1. 托盘图标右键 →「⚙️ 设置」→「③ 语音」
  2. 语音方案选「系统自带语音」→ 保存 → 把「语音总开关」设为「🔊 开启」→ 保存
  3. 让小狐狸说一句话试试（比如发一条聊天）
效果：微软系统中文语音（晓晓等），清晰自然但音色是大众化的。

方案二：edge-tts 云端语音（免费、音色好听）

需要 Python免费
  1. 安装 Python 3.9+（python.org，安装时勾选 Add python.exe to PATH）
  2. 打开命令行（Win+R → 输入 cmd → 回车），执行：
    pip install edge-tts
  3. 设置里：语音方案选「edge-tts 云端」→ 保存 → 打开语音开关
效果：微软神经网络语音（默认晓晓 zh-CN-XiaoxiaoNeural），免费无 Key。声音是通用的，不是苏苏洛。

方案三：本地克隆音色（Genie / GPT-SoVITS）★ 苏苏洛本人音色

需要 Python + 硬盘 2GB+CPU 就能跑

用本文件夹里的 genie_tts_server.py + 一段苏苏洛参考音频，就能克隆出苏苏洛的音色，全程本地、免费。

第 1 步：装 Python

安装 Python 3.9+（同上，勾选 Add to PATH）。

第 2 步：建环境并装 genie-tts

假设放到 D:GenieTTS（可自定，后面保持一致即可）。命令行执行：

mkdir D:GenieTTS
cd D:GenieTTS
python -m venv venv
venv\Scripts\pip install -r "语音部署与训练指南\requirements.txt"

注意：genie-tts 首次运行还会自动下载约 700MB 的语音模型资源（GenieData + 中文预置角色），走国内镜像，耐心等一次。

第 3 步：放服务器脚本和参考音频

  1. 把本指南文件夹里的 genie_tts_server.py 复制到 D:GenieTTS\
  2. 把 config.example.json 复制为 D:GenieTTS\config.json 并打开编辑：
{
  "character": "sussurro",
  "language": "Chinese",
  "refAudio": "D:\\GenieTTS\\ref\\ref_sussurro.wav",
  "refText": "你好呀，新手星，我是苏苏洛，罗德岛的医疗干员。今天也要好好休息哦。",
  "hfEndpoint": "https://hf-mirror.com"
}
  1. 把自己想克隆的音色参考音频（3~10 秒干净人声 wav）放到 D:GenieTTS\ref\ref_sussurro.wav，并把它的原文填进 refText（本指南自带一份苏苏洛示例音频 example_audio\，可直接复制用）

第 4 步：测试服务器

D:GenieTTS\venv\Scripts\python.exe D:GenieTTS\genie_tts_server.py --port 9881

看到 服务就绪 后，浏览器打开 http://127.0.0.1:9881/health 应显示 ok。首次启动会自动下载模型（约 700MB），耐心等待。

第 5 步：填进桌宠设置（或直接用程序内一键克隆）

  1. 设置 →「③ 语音」→ 语音方案选「本地克隆音色 Genie」
  2. Python 路径填：D:GenieTTS\venv\Scripts\pythonw.exe
  3. 服务器脚本填：D:GenieTTS\genie_tts_server.py
  4. 保存 → 打开语音开关。之后桌宠会自动拉起服务器，不用手动开

💡 换音色不用碰命令行：托盘 →「🎙️ 音色克隆与训练」窗口，选参考音频 + 填文本 →「试听」→「应用音色」，一键完成克隆并立即生效。

效果：克隆苏苏洛音色（参考音频是谁就是谁的声音）。CPU 即可实时合成；模型加载首次约 10~60 秒，之后秒回。
想训练出更像的音色？看旁边的「训练指南.html」。

方案四：百炼 CosyVoice 云端复刻

需要阿里云百炼 API Key付费
  1. 开通阿里云百炼，在控制台「声音复刻」上传参考音频生成音色 ID
  2. 设置里：语音方案选「百炼 CosyVoice」，在 config.json 的 ttsCosy 填入 apiKey 与 voice（音色 ID），保存并开语音

常见问题

  • 开了语音没声音？ 确认语音总开关是「🔊」；本地克隆的话先确认服务器 /health 返回 ok（可能是模型还在下载）
  • 服务器起不来？ 命令行直接跑 genie_tts_server.py 看报错；多半是 Python 版本或网络问题
  • 想换音色？ 换参考音频 + 对应 refText，重启服务器即可
  • 占不占显存？ Genie 是 CPU 推理，不占显存；约占 2~4GB 内存，建议内存 8GB+
