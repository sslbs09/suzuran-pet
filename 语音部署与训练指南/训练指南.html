🧪 音色克隆训练指南

想让苏苏洛（或任意角色）的声音更像原声？两条路：零样本克隆（快）或微调训练（精）。

先弄清：谁负责什么

本桌宠的本地语音用 Genie 推理（基于开源项目 GPT-SoVITS V2 的轻量 CPU 引擎）。

  • Genie：负责加载模型、参考音频克隆、把 GPT-SoVITS 的 PyTorch 模型转成 ONNX、提供 API。
  • GPT-SoVITS：负责「训练」——用你自己的音频数据微调出更贴合的音色模型。
  • 训练产出的 .pth + .ckpt 用 Genie 的 convert_to_onnx 转成 ONNX 后即可使用。

路线 A：零样本克隆（最简单，几分钟）

无需训练

💡 程序内一键完成：托盘 →「🎙️ 音色克隆与训练」窗口 → 选参考音频、填原文 →「试听」→「应用音色」即可，下面步骤交给程序处理。

  1. 准备一段 3~10 秒的干净人声 wav：单人、无背景音乐、无杂音、语速正常（本指南 example_audio\ 里有一份苏苏洛示例）
  2. 把音频放到 D:GenieTTS\ref\ref_sussurro.wav
  3. 把这段音频的逐字原文填到 D:GenieTTS\config.json 的 refText（必须一字不差，越准越像）
  4. 重启服务器即可
原理：GPT-SoVITS 用参考音频的声纹 + 情感来「模仿」说话。参考音频越干净、越接近日常说话，效果越好。
这是最常用的方式，绝大多数需求（包括苏苏洛本音）用这个就够了。

路线 B：微调训练（更像、更稳，需要几小时）

需要 GPU 更好，CPU 也能训（慢）

第 1 步：准备训练数据

  1. 收集目标角色的音频，切成 3~10 秒一段，建议 30 条以上（越多越像），wav/mp3 均可
  2. 给每段配好逐字文本（务必准确！）
  3. 建议先做降噪、去 BGM、统一响度（可用 Audacity）

第 2 步：用 GPT-SoVITS 训练

  1. 下载 GPT-SoVITS：github.com/RVC-Boss/GPT-SoVITS（官方有整合包和 WebUI，按 README 启动）
  2. 在 WebUI 里：① 数据标注导入音频+文本 → ② 语音切分（若未切）→ ③ 训练 SoVITS 与 ④ 训练 GPT（V2 模型，建议各训到 loss 不再明显下降）
  3. 训练完导出：SoVITS 模型 xxx.pth + GPT 模型 xxx.ckpt

第 3 步：转 ONNX（用 Genie）

先装 torch（转模型需要）：

D:GenieTTS\venv\Scripts\pip install torch --index-url https://download.pytorch.org/whl/cpu

再写个小脚本转换：

import os
os.environ["GENIE_DATA_DIR"] = r"D:GenieTTS\GenieData"
import genie_tts as genie

genie.convert_to_onnx(
    torch_pth_path=r"D:GenieTTS\my_model\你的角色.pth",   # SoVITS 模型
    torch_ckpt_path=r"D:GenieTTS\my_model\你的角色.ckpt", # GPT 模型
    output_dir=r"D:GenieTTS\my_model\onnx",               # 输出的 ONNX 目录
)
print("转换完成，输出在", r"D:GenieTTS\my_model\onnx")

第 4 步：让服务器用你的模型

编辑 D:GenieTTS\config.json：

{
  "character": "sussurro",
  "language": "Chinese",
  "modelDir": "D:\\GenieTTS\\my_model\\onnx",   ← 指向转换出的 ONNX 目录
  "refAudio": "D:\\GenieTTS\\ref\\ref_sussurro.wav",
  "refText": "参考音频原文",
  "hfEndpoint": "https://hf-mirror.com"
}

重启服务器即可（模型目录里需含 t2s_encoder_fp32.onnx、vits_fp32.onnx 等文件，Genie 会自动校验）。

⚠ 语言模型（GPT 部分）训练语料多来自通用数据，只微调少量你自己的音频也能明显提升相似度。训得越久越像，但别过拟合到只会说训练集的句子。

训练数据质量建议

  • 每条 3~10 秒，短而清晰 > 长而杂乱
  • 覆盖不同语气（陈述、疑问、感叹、轻笑）效果更好
  • 文本必须与音频逐字对应，这是相似度最重要的因素
  • 避免重音、耳语、夸张语气（会污染音色）
