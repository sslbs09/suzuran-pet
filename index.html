02 ANATOMY / HOW SHE LIVES

她不是一堆功能。
她是一套会回应的机制。

01

CHAT / MEMORY

她会记得，
但不是替你保管一切。

聊天支持任意 OpenAI 兼容接口，也支持 Anthropic 协议。DeepSeek 是默认端点，Kimi、GLM、Qwen、Ollama 等都可以在设置里接上。模型由你选择，Key 存在本机。

记忆分为事实、摘要和羁绊三层：她记住你的喜好与安排，每 20 轮对话生成一次印象摘要，互动会积累羁绊等级。所有内容都可以在设置里查看、编辑或删除。

02

VOICE / 5-LEVEL FALLBACK

可以只是文字。
也可以真的开口。

语音链路会从本地克隆音色，按顺序回退到百炼 CosyVoice、edge-tts 与 Windows 系统语音。完整版随包带中文和日语引擎；轻量版可以先部署引擎再打开语音。

想让她说日语，打开日语模式即可。回复会先翻译成日语，再用日语音色合成；文字气泡仍保留中文。

03

BODY / DESKTOP AS A MAP

桌面不是背景。
是她可以生活的地方。

GIF、Spine、2.5D、Live2D 四种渲染形态，从最稳的经典表情到可以行走的小人。透明区域点击穿透，不挡正常操作；置顶层级会周期重断言，全屏游戏后也能回来。

她可以换皮肤、换人设、自定义情绪，也可以让本机其他 AI 或脚本通过 127.0.0.1 的 Agent 接口找她聊天。接口可关闭，也可加 Bearer Token。

04

BOUNDARY / LOCAL FIRST

亲近不等于越界。
她的默认设置会守住边界。

程序不内置任何 AI 模型，聊天回复来自你自配的第三方接口。API Key 使用 DPAPI 加密存储在本机；本地 TTS 与 Agent 服务只监听 loopback。

需要联网时，是你主动选择的模型服务；需要被调用时，接口默认在本机，也能关闭。这是她住进来的前提，不是一句宣传语。

05 FIRST NIGHT / FIELD MANUAL

第一次见她，
从这里开始。

不用先研究所有功能。下载、解压、填一个 Key，再和她说一句话，就够了。

  1. 01

    下载并解压

    选择轻量版或完整版，解压整个文件夹。不要把 exe 单独拖出来运行，也不要把整个包放进快满的磁盘。

    DOWNLOAD / UNZIP
  2. 02

    启动，并同意使用条款

    双击解压后的 exe。第一次启动若出现 SmartScreen，点「更多信息」→「仍要运行」。同意条款后，她会出现在桌面上。

    RUN / ACCEPT
  3. 03

    填一个 API Key

    托盘图标右键 → 设置 → 聊天设置，填入服务商、端点、Key 和模型名，测试连接后保存。没有 Key？API 指南里整理了免费渠道。

    CONNECT / SAVE
  4. 04

    单击她，开始聊天

    单击小狐狸打开输入框，回车发送。第一次回复成功之后，剩下的就交给她和你自己慢慢摸索。
