## 追加：词库时间合理性全量审查 + 剪贴板 bug 修复（2026-08-30 晚）

**词库全量审查结论**：5 个时段池 + 事件池全部过了一遍。除已修"下午三点"外，另发现 5 处边界穿帮：
1. morning 池（5-11 点用）"今天的日出好漂亮" → 9-11 点说日出不合理 → "今天的天气看着不错"
2. morning 池"清晨的阳光真暖和" → 9-11 点说"清晨"勉强 → "早上的阳光真暖和……趁上午精神好"
3. evening 池（18-23 点用）"今天的晚霞很漂亮" → 20-23 点无晚霞 → "天边的暮色很温柔呢"
4. evening 池"睡前喝一杯牛奶有助于睡眠" → 18-19 点说"睡前"过早 → "晚上喝一杯温牛奶，睡得安稳些"
5. **wake 池整体**：原 4 条含"早安"——但 wake 在任意时刻睡醒都触发（含下午午休醒），说早安穿帮 → 全部改为中性睡醒词（"唔……睡得真舒服，精神好多了"等 8 条）

**剪贴板读取审查**（src/features.js startClipboardWatch），发现 3 个问题并修复：
1. **无 try/catch**：`clipboard.readText()` 在剪贴板被占用/锁定时会抛异常，定时器回调内未捕获 → 主进程异常。已补 try/catch，跳过本轮不中断监视。
2. **URL 只认 `http(s)://` 开头**：复制 `www.baidu.com` 裸域名识别不出。正则扩展为 `^(https?:\/\/)?([\w-]+\.)+[a-z]{2,}(\/\S*)?$`。
3. **数字判断过宽**：`/\d{10,}/` 会让"文本中夹带 10+ 位数字"（如长文本里的身份证号）误报"长数字"。收紧为 `^\d{10,}$`（整段是数字才算电话/订单号）。
