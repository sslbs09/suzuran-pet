# 🦊《快速开始》——苏苏洛桌宠新手教程

> 这份教程专门写给**第一次用桌宠的朋友**。
> 不需要懂电脑，只要会「双击、点点点」就能跟着做。每一步都有编号，照着做就行！

---

## 0. 这是什么？

苏苏洛是一只住在**你电脑桌面上**的小狐狸医生。

- 它会站在屏幕上陪你**聊天**（打字就行）
- 它可以变成小人在**任务栏上散步**，还会跳到窗口顶上坐着休息
- 它可以**说话**（可选，默认安静）

它就像一只电子小宠物：**你喂它一张「门票」，它就能开口说话。**

---

## 1. 开机：三步让它出现 🚀

1. **解压**：把下载的压缩包右键 →「全部解压」（建议解压到桌面）。
2. **双击**：找到 `苏苏洛桌宠 1.1 正式版.exe`，双击它。

   - 如果 Windows 弹蓝色警告框：点 **「更多信息」→「仍要运行」**（因为程序没有花钱买签名，不是病毒）。

3. **等 10 秒**：小狐狸出现啦！第一次启动会自动弹出「⚙️ 设置」窗口和条款页，点「同意」继续。

> ⚠️ 如果第一次什么都没弹出来，看屏幕**右下角任务栏**，找一个 🦊 小图标，**双击它**。

---

## 2. 喂门票：API Key 从哪里拿、怎么填 🎫

### 2.1 API Key 是什么？

桌宠自己不会说话，它要把你的话转交给**大模型公司**的电脑，才能回复你。

**API Key（钥匙）就是一张门票**：证明「你是付过钱的用户，可以进门」。

- 门票是**一串很长的字母数字**，长得像：`sk-abcd1234……`（这就是钥匙本尊，**不要给任何人看**！）
- 大部分公司**送免费额度**或**按量付钱很便宜**（聊几百句可能只要几毛钱）。

### 2.2 去哪里领门票？（选一家就行）

| 公司（服务商） | 去这个网站领 | 花钱吗 |
| --- | --- | --- |
| **DeepSeek**（推荐，便宜好用） | `platform.deepseek.com` | 注册送额度，之后很便宜 |
| 智谱 GLM | `open.bigmodel.cn` | 有免费额度 |
| Kimi 月之暗面 | `platform.moonshot.cn` | 送额度 |
| 阿里云百炼 Qwen | `bailian.console.aliyun.com` | 有免费额度 |
| 硅基流动 | `cloud.siliconflow.cn` | 有免费额度 |
| OpenAI | `platform.openai.com` | 需要国外支付方式 |
| Anthropic Claude | `console.anthropic.com` | 需要国外支付方式 |
| **Ollama 本地**（完全免费） | 不用领票！见下方 2.5 | **免费** |

### 2.3 手把手：领一张 DeepSeek 门票（5 分钟）

1. 打开浏览器，输入 `platform.deepseek.com`，回车。
2. **注册账号**（手机号就能注册）并登录。
3. 点左边的 **「API keys」**（有的版本叫「API 钥匙」）。
4. 点 **「创建 API key」**，随便起个名字，比如 `xiaohuli`。
5. 屏幕上会出现一串 `sk-` 开头的长字符——**这就是门票！**

   - 📋 点旁边的「复制」按钮，把它复制下来。
   - ⚠️ 这个窗口关掉后就再也看不到了（只能重新建一张），所以现在就把它**粘贴到记事本存一下**。

### 2.4 手把手：把门票放进桌宠（2 分钟）

1. 右键点击任务栏的 🦊 小图标 → 点 **「⚙️ 设置」**。
2. 在「**① 聊天 API**」区域：

   - 「服务商预设」选 **DeepSeek**（地址和模型名会自动填好，不用动）。
   - 找到「**API Key**」输入框，点进去，**粘贴**（Ctrl+V）你刚复制的门票。

3. 点 **「🔌 测试连接」**：

   - 看到 ✅「连接成功」→ 太棒了，进下一步！
   - 看到红字 → 看下面第 4 章「小诊所」对症下药。

4. 点 **「💾 保存 API 设置」**。
5. 回到桌宠，**单击小狐狸** → 弹出输入框 → 打个招呼，回车！它会回你话啦 🎉

> 💡 顺便把「桌宠对你的称呼」改成你的名字，它会这么叫你。
> 💡 你的门票会被**加密锁进本机的保险箱**（见第 5 章），放心。

### 2.5 完全不想注册/花钱？用免费的 Ollama

1. 去 `ollama.com` 下载 Ollama，安装后它会躲在后台。
2. 按键盘 `Win + R`，输入 `cmd` 回车，在黑窗口输入 `ollama pull qwen2.5:7b` 回车（下载一个免费模型，约 5GB，要等一会）。
3. 桌宠设置 → 服务商预设选 **Ollama（本地免费）** → API Key **留空** → 测试连接 → 保存。

- 特点：**完全免费、断网也能聊**，但需要你的电脑配置还行，且回复没那么聪明。

### 2.6 懒人通道：一键导入（电脑上有 ZCode / 百炼的朋友）

如果你的电脑本来就在用 ZCode 或阿里云百炼，桌宠可以**直接借用已经存好的钥匙**，不用重新注册：

1. 打开桌宠「⚙️ 设置」，拉到最下面「**⑤ 密钥与凭据安全**」。
2. 点 **「🔍 扫描本机可导入凭据」**——它会找出电脑里已有的钥匙（**只显示指纹**，比如 `sk-a…z9`，不会显示完整钥匙）。
3. 在下拉框里选中一把，选好用途（聊天 Key / CosyVoice Key）。
4. 点 **「⬇ 导入所选凭据」** → 弹窗点「确定」→ 完成！

> 放心：导入只是**复制**一份锁进桌宠自己的保险箱，原来的文件一个字都不会被改动。

## 3. 日常怎么玩 🎮

### 和它聊天

- **单击**小狐狸 → 弹出输入框 → 打字 → 回车。
- 点输入栏的 **■** 按钮可以打断它的话。

### 搬家

- **按住**小狐狸**拖动**，想到哪就到哪（聊天气泡会跟着走）。
- 用力一甩还能**扔出去**，它会自己飞出去、弹回来落地（放心，摔不坏）。

### 收起来 / 叫出来

- **右键**小狐狸 → 隐藏到托盘。
- 随时按 **`Alt + Shift + S`**（三个键一起按）让它出现/消失。

### 所有功能的总开关：托盘菜单

右键任务栏 🦊 图标，里面有：设置、使用说明、表情管理、换皮肤、语音开关、散步速度……

### 换成会走路的小人（Spine 模式）

1. 托盘右键 → ⚙️ 设置 → 「④ 其他」→「渲染模式」选 **Spine 小人模型** → 保存。
2. 勾选「🚶 桌面行走」→ 小人会以**任务栏上沿为地面**散步，偶尔跳到窗口顶上坐着。
3. 托盘「🧩 小人皮肤」可以换衣服/换角色。
4. 想放自己的模型？把 `.atlas + .skel + .png` 三个文件放进这个文件夹（没有就自己建）：

   `C:\Users\你的用户名\AppData\Roaming\苏苏洛桌宠 1.1 正式版\assets\spine\user\`
   重启桌宠就会出现在皮肤菜单里。

### 开声音（可选）

语音默认关闭。想听它说话：设置 → 「③ 语音」→ 打开总开关，选一个方案（系统语音零配置；更厉害的克隆音色看「语音部署与训练指南」文件夹）。

## 4. 出毛病了怎么办？——故障小诊所 🏥

> 对号入座：找到你的「症状」，照「药方」做。

### ① 双击 exe 没反应 / 被蓝色警告拦住

- **药方**：点「更多信息」→「仍要运行」。还不行就确认解压完整（文件夹里要有 `resources` 文件夹），换个路径（别放需要管理员权限的 C 盘根目录）再试。

### ② 它说「未配置 API Key」

- **药方**：门票还没喂。回到第 2.4 节，把 Key 填进去 → 测试连接 → 保存。

### ③ 点「测试连接」出红字

- 红字说 **401 / 认证失败** → 门票抄错了。回官网**重新创建一张**，重新复制粘贴（前后别带空格）。
- 红字说 **402 / 欠费 / 余额不足** → 去服务商官网充值，或换一家有免费额度的。
- 红字说 **404 / 模型不存在** → 模型名写错了。点「🔍 获取模型列表」自动选一个。
- 红字说 **超时 / 网络** → 检查网线/WiFi；用 OpenAI/Claude 需要能访问国外网站。

### ④ 聊天发出去石沉大海

- 依次检查：输入框打开了吗（单击小狐狸）→ 是不是欠费了（见③）→ 还不行就**重启桌宠**（托盘右键 → 退出，再双击 exe）。

### ⑤ 桌宠不见了

- 看任务栏右下角有没有 🦊 小图标，**单击它**就回来了。
- 或者按 **`Alt + Shift + S`**。

### ⑥ 鼠标点不到桌宠 / 点它没反应

- 桌宠周围的**透明区域**点不到是正常的（设计如此，不挡你操作别的软件）。
- 请瞄准**小狐狸身体本身**单击；实在不行从托盘菜单把它重新显示一次。

### ⑦ 屏幕弹出「A JavaScript error occurred in the main process」

- 这是桌宠**打了个喷嚏**（内部小故障），不是你电脑坏了。
- **药方**：点「确定」关掉弹窗 → 重新双击 exe 打开桌宠。
- 新版本已经装了「防摔垫」（自动拦截这类故障），一般不会再弹。**如果同一个错误反复出现**：记住发生的时间，按第 6 章找人报告。

### ⑧ 语音没声音

- 先检查：设置 → 语音总开关开了吗？输入栏的 🔊 按钮是开着的吗？
- 选「系统自带语音」最稳；克隆音色需要按指南部署本地服务（看「语音部署与训练指南」文件夹）。

### ⑨ 人设/设置被我改乱了

- 人设乱了：设置 → 「② 人设」→「↩ 恢复默认人设」。
- 聊天记录想清空：设置 → 「🗑 清除聊天记录」。
- 全乱套了：托盘右键 → 退出，把设置里能恢复的都恢复；实在不行删掉配置文件让它重新开始（**会丢聊天记录和人设**，钥匙不受影响）——这招先找懂电脑的朋友陪着你用。

## 5. 密钥安全小课堂 🔐

- 你的 API Key 存在**你自己电脑的加密保险箱**里（Windows 系统级加密），配置文件里看不到明文，别人拿到文件也解不开。
- 想确认状态？设置 → 「⑤ 密钥与凭据安全」：三个小徽标会显示「已保存 / 未保存」。
- 想换钥匙：直接在输入框填新的，保存即替换。想删掉：点对应的「清除」按钮。
- **三不原则**：不把 Key 发到群里、不截图给别人、不填到来路不明的软件里。

---

## 6. 找人帮忙时怎么说 🆘

报告问题像医生问诊，说清这四件事：

1. **症状**：你想做什么，发生了什么（最好**截一张图**）。
2. **时间**：大概几点出现的。
3. **做过什么**：比如「填了 Key、点了测试连接」。
4. **日志**：让懂电脑的朋友打开这个文件夹里的 `tts.log`：

   `C:\Users\你的用户名\AppData\Roaming\苏苏洛桌宠 1.1 正式版\logs\`
