# 技术债台账（2026-09-03 建档）

> 来源：v2.5.27 合并批次部署后的遗留项与在办调查。每项含现状、证据、下一步。
> 处理约定：一次只做一项，做完回归 `npm test`（当前基线 40/40）再部署。

## TD-1（在办）：winter 皮肤坐姿"悬空"——气泡打开时画布锚点错位

- 现象：偶发坐着但明显悬在任务栏上方，几秒/起身后自愈；用户截图时气泡是展开的。
- 探针数据（扩展版，已部署）：
  - 主进程：`自主休息: y=768 h=200 sink=30 gap=26 tier=standard`
  - 渲染层：`[fit-probe] Sit H=120 visibleGap=0 cssGapBelow=26 innerH=200 canvasBottom=174 zoom=1`
- 推算：坐姿可见底边 = 窗口y + 画布底(174)。气泡收起时 butt=768+174=942，任务栏沿口=912，
  即坐进沿口下 30px——**几何正确**。悬空只可能发生在窗口为气泡撑高、画布在窗口内
  锚点改变的时刻：坐休/自愈公式只保证"窗口底"位置，不重算画布偏移。
- 下一步：
  1. 在气泡开/关（ensureWindowWidthFor、setSize 路径）时补一次 applySeatPosition 重锚，
     或让画布 CSS 固定贴窗口底边（更根本，需核对输入栏/信息版布局依赖）；
  2. 探针在气泡打开状态下补采一组数据验证假设；
  3. 坐姿自愈周期 5s 是悬空可见时长的上限，改完应降到 0。
- 风险：动窗口布局会牵连气泡定位/翻边/点击穿透，务必小步+真机验证。

## TD-2：pendingAmbient 无过期时间

- 现状：后台消息被忙/睡拦截后暂存，无 TTL；极端情况下几分钟后仍可能补发旧消息。
- 下一步：pendingAmbient 加 createdAt，flush 时超过 2-5 分钟直接丢弃并记日志。

- 下一步：加总大小上限（如 500MB）与 LRU 目录清理；或启动时自动清非当前 fingerprint。
