## 六、易踩的坑（本轮实录，接手必读）

- **pet.js 改动后启动崩/点击失灵**：先怀疑渲染层 JS 运行时错误——pet.js 已有 `[jserr]/[jsrej]` 全局错误上报（写 tts.log），第一时间拉日志。
- **heredoc 写含 `\n` 的 JS/正则会把转义写成真实换行**（bash 转义陷阱，本轮踩了 3 次）：用 Write 工具写文件，或 python 用 `chr(92)+'n'` 构造。
- **pack 前忘了 cp 同步 / pack 后忘了重启**：部署三步（cp→pack→重启）缺一不可；**pack 前必须停桌宠**。
- **替换 asar 前确认桌宠全停**：进程残留会锁文件（朋友设备"删改文件要重启电脑"即此）。
- **python 相对路径**：每个 Bash 调用的 cwd 可能被重置，用绝对路径或显式 cd。
- **git push 节奏**：调好+用户验收才 push（用户明确要求）。
