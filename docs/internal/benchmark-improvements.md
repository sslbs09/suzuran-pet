# 桌宠竞品对比与改进建议（2026-08-26）

对比对象：VPet（Steam 标杆）、Shimeji、Desktop Mate、Ark-Pets、Bongo Cat、Desktop Goose、eSheep、桌宠引擎、VPetlings、Meowker 等 20+ 款。

## 一、我们已有（对标竞品标配）
- 渲染：GIF / Spine / PSD 2.5D 三模式（超过多数竞品单一模式）
- 行为：桌面行走、任务栏坐姿、窗口顶驻留、桌面图标感知、拖拽抛掷、逗猫棒追鼠标
- 交互：点击互动、鼠标停留互动、2.5D 头眼跟随、全局鼠标跟踪（Live2D 级追踪）
- AI：聊天（多服务商）、情绪响应、主动搭话、Agent API、蜜标防御
- 语音：日语语音模式（翻译+GSV 本地音色）、多 TTS 引擎
- 提醒：日程（Excel 导入/预览）、番茄钟、系统监控、开机自启、点击穿透、置顶切换

**已覆盖竞品核心**：点击穿透✓ 置顶切换✓ 开机自启✓ 坐任务栏/窗顶✓ 拖拽✓ 鼠标光标互动✓ AI 对话✓ 皮肤导入✓ 托盘✓ 省电降帧✓ 多语言✓

## 二、我们没有的（改进点，按价值排序）

### A 类：低成本高价值（推荐先做）
1. **音乐响应**（跟音乐跳舞/摇摆）——桌宠引擎/Desktop Mate 标配，低成本高情绪价值。检测系统音频（或简单节拍），角色随节奏摆/跳。
2. **摸头互动**（头部区域交互）——VPet/Desktop Mate 核心萌点。现在点击是统一互动，可区分"摸头"（头部区域→专属摸头动画+台词）。
3. **人格化状态台词**（事件驱动消息）——MateEngine：拖拽/坐下/跳窗/追鼠标时冒可爱台词（如"抓住我啦！"）。我们有主动搭话，扩展成场景事件触发，成本低。
4. **快速翻译/搜索**（工具位）——MagicPet：选中文字翻译/搜索（桌宠当工具）。我们已有翻译能力，做成"翻译当前剪贴板/选中"。

### B 类：中成本（值得做）
5. **人格化状态系统**（心情/作息/会饿会困）——VPet 口碑核心（"饿了会闹、无聊自己玩"）。数值化心情/饱食/疲劳 + 对应动画/表情/台词。与现有情绪系统融合。
6. **丢接球小游戏**——VPetlings：玩家"扔"球，桌宠去追/叼回。我们已有抛掷物理，扩展成互动游戏。
7. **观察 AI 工作流吐槽**——cc-haha/clawd-on-desk（2025 新品类）：桌宠观看 Claude Code/Codex 工作状态并吐槽。**我们已有 Agent API + ZCode 集成——天然契合**（桌宠看 ZCode 在干什么，偶尔吐槽/加油）。
8. **通用主动搭话增强**——Pet-GPT：AI 主动发起聊天（问候/天气/时间/工作提醒）。我们已有主动搭话，扩展场景与频率。

### C 类：高成本/需权衡
9. 喂食/养成数值系统（VPet/Meowker）——完整养成（喂食/清洁/打工赚币）
10. 屏幕理解/AI 视觉（我的桌宠AIO）——桌宠"看"屏幕点评/翻译（需屏幕捕获，隐私敏感）
11. 开放插件 SDK/创意工坊（VPet workshop）——插件化扩展（我们有 PSD 导入近似）
12. 屏保模式、音乐播放器小部件（MateEngine/Live2DViewerEX）

### 用户明确不要
- 多桌宠同屏互斥（Shimeji 类）

## 三、推荐路线（结合"苏苏洛 AI 桌宠"定位）
1. **A1 音乐响应**（跟音乐摇摆/跳舞）——最快见效
2. **A3 人格化事件台词**（拖拽/坐/跳窗时冒台词）——增强"活着"感
3. **A2 摸头互动**——萌点强化
4. **B7 观察 AI 工作流**——独特点（我们已有 Agent API/ZCode 集成）
5. **B5 人格化状态**（心情/作息）——中期口碑项
