**一分钟扫盲**（常见词先见个面）：
- **托盘** = 屏幕右下角、时间旁边那一排小图标（桌宠最小化后在这里）。
- **API Key** = 一张"钥匙"，让桌宠能调用 AI 服务；放在你自己电脑的保险柜里（见 06）。
- **配置** = 桌宠的"设置记事本"，记录你改过的所有选项。
- **Spine / GIF / PSD** = 三种"皮肤"格式：GIF 是动图、Spine 是游戏级可动模型、PSD 是分层图片（可自己拆）。
- **GPT-SoVITS / Genie / GSV** = 一个"语音模仿秀"程序的不同叫法，装在你电脑上，让桌宠用克隆的声音说话（见 04）。
