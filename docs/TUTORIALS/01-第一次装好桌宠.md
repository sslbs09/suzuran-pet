# 01 · 第一次装好桌宠

## 把它请出来
1. 把 `苏苏洛桌宠 2.5 正式版` 这个文件夹放到你喜欢的地方（桌面最顺手）。**整个文件夹要一起留着**，别只拖 exe 出来——它需要旁边 `resources` 文件夹里的零件才能跑。
2. 双击里面的 `苏苏洛桌宠 2.5 正式版.exe`。
3. 第一次打开会先看到《使用条款》，读完点**同意并开始使用**。
4. 屏幕边上就会出现一只粉毛小狐狸——恭喜，她活了 🎉

> **黑话翻译**：exe = 桌面宠物的"身体"，resources = 它身体里的"器官"。两者缺一不可。

## 它不说话？先做这三件事
| 现象 | 原因 | 解决 |
|---|---|---|
| 一点声音没有 | 语音默认是关的 | 设置 → ③语音 → 打开"语音总开关" |
| 说了话但不像苏苏洛 | 还没接本地日语声库 | 见教程 04 |
| 还没聊过天 | 它要先"醒" | 点它一下（这是摸头，见教程 05），或者直接说句话 |

## 托盘是它的"后台"
点右上角的最小化，它不会消失，而是缩到**托盘**（屏幕右下角、时间旁边）。在托盘小图标上右键，能：隐藏/显示它、开关行走、打开设置、退出。

## 三个最容易踩的坑
- ❌ **只拷了 exe 给别人** → 对方打不开。要拷**整个文件夹**。
- ❌ **杀毒软件把 exe 拦了** → 这是常见的误报；把文件夹加入信任/白名单即可（它是纯本地程序，不会联网上传你的隐私，见教程 06）。
- ❌ **想改文件却找不到它在哪** → 它所有的"记忆"和"悄悄话"都存在你的用户目录里，见教程 06 的路径表。
