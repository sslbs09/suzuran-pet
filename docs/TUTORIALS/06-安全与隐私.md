# 06 · 它的安全与隐私（密钥 / 防篡改 / 分享前检查）

## 一句话：全本地、不上传
苏苏洛默认**不联网上传任何隐私**。它的记忆、聊天记录、密钥全部存你电脑本地。
唯一的联网是：你配置的 AI 服务 / 语音服务（比如 DeepSeek 的聊天接口、本地语音合成程序 GPT-SoVITS），那是你主动给它的"电话线"。

## 你的 API Key 放在哪、安不安全
- 钥匙（API Key，就是一行像账号密码一样的长字符）优先放进 **系统保险柜**（Windows 自带加密，只有你这个 Windows 用户能解开），设置页会标注密钥来源是"安全本地存储"。
- 配置文件的路径：`C:\Users\你的用户名\AppData\Roaming\苏苏洛桌宠 2.5 正式版\`（config.json 是设置、memory.json 是记忆、bond.json 是羁绊）。

## 防偷、防改（蜜标 + 篡改自愈）
桌宠自带三道"保安"（默认可选开，在设置 → 实验性开启"蜜标监控"）：
1. **蜜标诱饵**：放两个假文件（带假钥匙的那种），谁碰它们它都知道（`_honeytoken_*`）。
2. **篡改检测**：配置文件被外部改了 → 自动**恢复成干净版本**，并把被改的内容备份成 `config.json.tampered` 供你检查。
3. **异常新文件监控**：用户目录突然出现可疑 exe/脚本（疑似木马复制），会提示。

> 这些小"保安"都是官方安全测试（在隔离虚拟机里）验证过的：
> 读诱饵文件被当场抓到、改配置被检测到且自动还原 ✅

## 想分享 / 打包给别人？先做这 3 步
1. **删掉或清空** `resources\app\config.json` 和安装根 `config.json` 里的密钥字段（以前装/更新时可能残留过真实钥匙——别把钥匙送人）。
2. 删掉 `AppData\...\苏苏洛桌宠 2.5 正式版` 里的 config/memory/bond（那是你的私密数据）。
3. 只打包程序文件（不含上面的用户数据）。

## 日志在哪
`AppData\...\苏苏洛桌宠 2.5 正式版\logs\tts.log`——出问题给开发者看这个文件最有用（里面是它的"体检报告"）。

## 那个"记忆文件异常"提示？
正常情况下只在**真的被外部改动/加密异常**时出现（并自动重置）。如果你从未见过或偶尔见到一次，大概率没事；若**每次启动都弹**，把日志发给我，现在日志里会带具体原因（v2.6 新增），一眼能定位。
