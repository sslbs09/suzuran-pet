# 04 · 让桌宠开口说日语（GPT-SoVITS 语音保姆级）

目标：让小狐狸用**日语**说话、有**撒娇/傲娇/惊讶/温柔/开心**五种情绪音色（参考音频制）。

## 前置：GPT-SoVITS 日语声库
1. 装好 GPT-SoVITS（一个运行在你电脑上的"语音模仿秀"程序，推荐 v2ProPlus），记下它的地址，一般是 `http://127.0.0.1:9880`。
2. 设置 → ③语音：
   - 语音总开关：打开
   - 方案：选 **本地克隆音色 Genie**（Genie 是这个语音程序的叫法，它内部走的引擎叫 GSV，选 Genie 就行）
   - 勾选 **🗣 日语语音模式**（界面文字仍是中文，只有说话翻译成日语）
   - 填 **Python 路径 / 服务器脚本**（就是刚才那个程序在电脑里的安装位置，一般在声库安装包里能找到）
   - 保存；可点"重启日语语音服务"看是否报错

> 黑话翻译：端口 9880 = 声库的"电话线号码"，桌宠通过它叫人接线。

## 情绪音色（五档）
桌宠自带**参考音频**（already 配好）：撒娇/傲娇/惊讶/温柔/开心，各对应一段苏苏洛日语音频。
- 设置 → ③语音 → 「情绪音色试听」：六个按钮（默认/撒娇/傲娇/惊讶/温柔/开心）**一键试听**。
- 同一档下方有"音色启用"勾选：**不想要的档关掉**，那情绪说话时就回默认音色/语气。

原理一句话：GPT-SoVITS 像"模仿秀"，给它听一段参考音频（模仿对象）+ 台词，它就学着那段声音说话——所以参考音频选得好，情绪才像。

## 想换/加强某档
1. 找一段更想要的苏苏洛日语原声（比如 PRTS 官网的语音）。
2. 放到 `resources\app\voice-ref\`，命名 `ref_情绪名.trim.wav`，附 `.txt` 写台本。
3. 改 `resources\app\voice-refs.json` 对应条目（file=文件名，text=日语原文）。
4. 回设置页点试听验证；不满意就停用那档，不影响其它。

## 遇到问题
| 现象 | 检查 |
|---|---|
| 没声音 | 总开关 + 日语模式 + 语音服务（GSV）是否在 9880 端口正常运行（9880 是它的"电话线号码"，见开头） |
| 说话是中文 | 没勾日语模式 |
| 试听失败 | 参考音频文件在不在 / GSV 服务是否可用 |
| 卡在"正在连接" | 看声库控制台日志，确认模型加载完成（首次要几分钟） |
