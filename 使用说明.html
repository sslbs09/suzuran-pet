🦊 苏苏洛桌宠 · 使用说明

罗德岛医疗干员 · 你的专属桌宠（绿色免安装版）——会聊天、会说话、会在桌面上散步、会记住你的事。
⚠ 第一次运行被 SmartScreen 拦截？这是程序没买数字签名导致的正常提示：点「更多信息」→「仍要运行」即可。放心，这是绿色程序，不解压到别处也能用。

🚀 三步开始使用

  1. 双击 苏苏洛桌宠.exe
  2. 首次启动会自动弹出「⚙️ 设置」：选服务商 → 填 API Key →「测试连接」→「保存」；再把「桌宠对你的称呼」改成你的名字
  3. 单击小狐狸 → 输入框 → 回车，开始聊天 🩺

🖱 日常操作

  • 单击小狐狸：打开/关闭聊天框
  • 按住拖动：移动位置（会自动记住）
  • 右键小狐狸 或 Alt+Shift+S：隐藏/显示
  • 右下角托盘图标：单击隐藏/显示，右键打开菜单（设置、重载人设、退出等）
  • 透明区域完全点击穿透，不挡其他软件

⚙️ 配置 API 与换人设

  • 托盘右键 →「⚙️ 设置」：API（支持 DeepSeek / Kimi / OpenAI / GLM / Qwen / 本地 Ollama 等）、称呼、人设编辑、语音方案，都在这里
  • 人设里 {{userName}} 会自动替换成你的称呼，保存立即生效，不用重启
  • 托盘 →「🎙️ 音色克隆与训练」：部署好本地 Genie 后，在窗口里选参考音频、填文本、试听、一键应用，就能直接克隆出喜欢的音色（全界面操作，不用命令行）
  • 「语音部署与训练指南」文件夹里有开语音的完整教程（默认是关的，文字交流不需要）

🎁 其他

  • 托盘 →「🎨 表情管理」：每个情绪单独换 GIF，还能自己加情绪（≤5 个字，最多 30 个）——AI 回复时会自动选最贴切的情绪表现
  • 高级配置：resources\app\config.json 可改热键、窗口尺寸、记忆轮数、情绪表等
  • 任务模式（/zcode 前缀操控电脑）：默认关闭，需要另装 ZCode 才能用

⚠ 重要说明

关于 AI 回复：聊天回复来自你自配的 OpenAI 兼容接口（第三方服务），程序不内置模型；API Key 只存在你本机（加密存储），不上传。
关于引擎：完整版含语音引擎（约 15GB），删除 engines 后语音不可用（聊天不受影响）。
