🐣 快速开始 · 新手教程

写给第一次用桌宠的你：会「双击、点点点」就能跟着做

① 开机：三步让它出现

  1. 解压：压缩包右键 →「全部解压」（建议放桌面）。
  2. 双击 苏苏洛桌宠 1.1 正式版.exe。弹蓝色警告就点「更多信息」→「仍要运行」（程序没买签名，不是病毒）。
  3. 等 10 秒：小狐狸出现！首次启动自动弹设置和条款页，点「同意」继续。

⚠️ 没弹出来？看屏幕右下角任务栏找 🦊 小图标，双击它。

② 喂门票：API Key 从哪里拿、怎么填

桌宠要把你的话转给大模型公司才能回你。API Key 就是一张门票：一串 sk-… 开头的长字符，不要给任何人看。多数公司送免费额度，聊几百句可能只要几毛钱。

DeepSeek（推荐）去 platform.deepseek.com 注册 → 左侧「API keys」→「创建」→ 复制那串 sk-…（窗口关了就看不到了，先存记事本）
其他服务商智谱 open.bigmodel.cn · Kimi platform.moonshot.cn · 百炼 bailian.console.aliyun.com · 硅基流动 cloud.siliconflow.cn —— 都是注册后在「API Key / 密钥」页面创建
完全免费方案Ollama 本地：ollama.com 下载安装 → 命令行 ollama pull qwen2.5:7b → 桌宠预设选 Ollama，Key 留空。免费断网可用，但需要电脑配置还行

拿到钥匙后，填进桌宠只要 2 分钟：

  1. 右键任务栏 🦊 图标 →「⚙️ 设置」。
  2. 「① 聊天 API」→ 服务商预设选 DeepSeek（地址模型自动填好）→ 把钥匙粘贴进「API Key」输入框。
  3. 点「🔌 测试连接」→ 看到 ✅ 连接成功 → 点「💾 保存 API 设置」。
  4. 单击小狐狸 → 输入框打个招呼 → 回车，它会回你啦 🎉

③ 懒人通道：一键导入已有钥匙

电脑上本来就在用 ZCode / 阿里云百炼？桌宠可以直接复制已存好的钥匙：

  1. 设置拉到最下面「⑤ 密钥与凭据安全」。
  2. 点「🔍 扫描本机可导入凭据」（只显示指纹 sk-a…z9，不显示完整钥匙）。
  3. 选中一把 → 选用途（聊天 Key / CosyVoice Key）→「⬇ 导入所选凭据」→ 确定。

💡 导入只是复制一份锁进桌宠自己的保险箱，原文件一个字都不会被改动。

④ 日常怎么玩

聊天单击小狐狸 → 输入框打字 → 回车；「■」按钮打断回复
搬家 / 抛掷按住拖动；用力一甩会飞出去再落地（摔不坏）
收起 / 叫出右键小狐狸隐藏；随时按 Alt + Shift + S 叫回来
换小人走路设置 →「④ 其他」→ 渲染模式选 Spine 小人模型 → 勾选「🚶 桌面行走」；托盘「🧩 小人皮肤」换角色
放自己的模型把 .atlas + .skel + .png 放进
C:\Users\你的用户名\AppData\Roaming\苏苏洛桌宠 1.1 正式版\assets\spine\user\
重启即出现在皮肤菜单
开声音设置 →「③ 语音」打开总开关；系统语音零配置，克隆音色看「语音部署与训练指南」

⑤ 故障小诊所（对症下药）

双击没反应 / 被拦点「更多信息」→「仍要运行」；确认解压完整，别放 C 盘根目录
说「未配置 API Key」门票还没喂：照上面 ② 填 Key → 测试 → 保存
测试连接出红字401=钥匙抄错，回官网重建一张；402/欠费=去充值或换免费家；404=模型名错，点「🔍 获取模型列表」自动选；超时=查网络
聊天石沉大海输入框开了吗 → 是不是欠费 → 重启桌宠（托盘右键退出再双击 exe）
桌宠不见了点任务栏 🦊 图标，或按 Alt + Shift + S
点不到桌宠周围透明区点不到是正常设计；瞄准小狐狸身体点，或从托盘重新显示
弹「A JavaScript error」桌宠打了个喷嚏，不是电脑坏了：点「确定」→ 重新打开 exe。新版已装「防摔垫」，反复出现再报告（记下时间）
语音没声音设置里语音总开关 + 输入栏 🔊 都开了吗？系统语音最稳
人设/设置改乱了设置 →「② 人设」→「↩ 恢复默认人设」；「🗑 清除聊天记录」清历史

⑥ 密钥安全 & 求助

  • 钥匙存在你电脑的加密保险箱（Windows 系统级加密），配置文件里看不到明文；状态看「⑤ 密钥与凭据安全」徽标，可随时清除。
  • 三不原则：不发群里、不截图给别人、不填来路不明的软件。
  • 找人求助说清四件事：症状（截图）+ 时间 + 做过什么 + 日志（%APPDATA%\苏苏洛桌宠 1.1 正式版\logs\tts.log）。
