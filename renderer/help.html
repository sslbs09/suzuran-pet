🦊 苏苏洛 · 使用说明

罗德岛医疗干员 · 你的专属桌宠（分享版）

快速开始（三步）

1. 右键托盘图标「⚙️ 设置」→ 选择服务商（DeepSeek / Kimi / OpenAI / 本地 Ollama…）→ 填写 API Key →「测试连接」→「保存」
2. 设置称呼在设置里把「桌宠对你的称呼」改成你喜欢的名字（人设里会自动替换）
3. 开始聊天单击小狐狸弹出输入框，回车发送；想改人设就打开「⚙️ 设置」→「人设」直接编辑

日常操作

单击小狐狸打开 / 关闭输入栏（聊天框）
按住拖动移动桌宠（对话框跟随）
右键小狐狸隐藏到托盘（Alt+Shift+S 全局隐藏/显示）
透明区域点击穿透，完全不影响其他应用操作
托盘图标单击隐藏/显示；右键有「设置 / 使用说明 / 语音部署与训练 / 重载人设 / 退出」

聊天

直接输入文字日常聊天，苏苏洛用罗德岛医师口吻回你
■ 停止按钮中断当前回复
聊天记忆自动记住最近若干轮对话（可在设置里调整）

语音（可选，默认关闭）

默认状态语音关闭，桌宠用文字气泡交流，无需任何额外安装
想开语音？托盘 →「🎤 语音部署与训练」打开指南，按方案选一个（系统语音零配置 / edge-tts / 本地克隆音色 / 百炼 CosyVoice）
🔊/🔇 按钮输入栏右侧一键开关语音
💡 小提示：没配 API Key 时首次启动会自动弹出设置窗口；换肤/改人设都不需要重启，托盘「重载人设」立即生效。
