① 聊天 API

Ollama 本地模型无需 Key（地址填 http://localhost:11434/v1）；其他服务商按各自的 OpenAI 兼容地址填写。

② 人设（角色设定）

编辑下方内容即可自定义角色。占位符 {{userName}} 会自动替换成上面填的称呼，{{petName}} 替换成桌宠名字。保存后立即生效。

③ 语音（可选，默认关闭）

④ 其他

其他 agent / 脚本可调用：POST http://127.0.0.1:8765/chat，请求体 {"text":"苏苏洛 帮我…"}；GET /health 查状态。仅监听本机，不对局域网开放。

任务模式（/zcode 前缀操控电脑）默认关闭：想开启请打开 config.json，把 zcodeEnabled 改为 true 并配置 zcodeCli 路径（需自行安装 ZCode）。
