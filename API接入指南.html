🔌 API 接入指南（学生党白嫖版）

桌宠的聊天靠大模型 API 驱动。这篇教你从零拿到 Key、填进桌宠，顺便把能白嫖的渠道都列给你。额度政策随时会变，动手前以各家官网为准。

一、先搞懂：桌宠要填哪三样

打开托盘菜单 → 设置 → 聊天设置，就三样东西：

  1. API 端点（baseUrl）——接口地址，决定你用哪家的模型
  2. API Key——你在这家网站的"通行证"，一串字符
  3. 模型名——具体用哪个模型，比如 qwen-plus、glm-4-flash

桌宠支持两种协议：OpenAI 兼容（绝大多数家都用这个）和 Anthropic（Claude 官方）。选对协议，填对地址就行。

免费额度政策变动很频繁，下面的步骤是通用路子，具体金额和期限请以官网页面为准。

三、阿里云百炼 + 学生 300 元券（重点推荐学生党）

第 1 步：领学生券（云工开物计划）

  1. 打开 university.aliyun.com（阿里云云工开物·高校计划）
  2. 用支付宝/淘宝账号登录，完成学生认证（学信网学籍信息）
  3. 在权益页领 300 元无门槛优惠券——大模型（百炼）也在适用范围里

第 2 步：开通百炼拿新人额度

  1. 进 bailian.console.aliyun.com 开通"百炼"大模型服务平台
  2. 新人自动送免费额度（开通后约 90 天内有效），150+ 款模型都能用
  3. 重要：在费用设置里打开「用完即停」开关——额度用完自动停，不会偷偷扣你钱
  4. 左侧「API-KEY」页面 → 创建 API Key → 复制保存

第 3 步：填进桌宠

项填什么
协议OpenAI 兼容
端点https://dashscope.aliyuncs.com/compatible-mode/v1
Key刚创建的 sk-xxx
模型名qwen-plus（均衡）或 qwen-turbo（快、便宜）

学生券额度用完，还可以关注百炼的「先用后返」「全模型抵扣包」活动接着薅。

四、其他渠道快速上手

长期免费智谱 GLM

  1. 注册 open.bigmodel.cn（智谱开放平台），手机号就行
  2. 在「API Keys」页面创建 Key
  3. 端点 https://open.bigmodel.cn/api/paas/v4，模型填 glm-4-flash——这个档位免费，日常聊天够用

注册送额度硅基流动 SiliconFlow

  1. 注册 siliconflow.cn，送一笔体验额度
  2. 端点 https://api.siliconflow.cn/v1
  3. 模型列表里挑带「免费」标记的小模型（如 Qwen/Qwen2.5-7B-Instruct，以站内标注为准）

需网络条件Google Gemini

到 aistudio.google.com 用 Google 账号登录，点「Get API key」生成。OpenAI 兼容端点是 https://generativelanguage.googleapis.com/v1beta/openai/，模型如 gemini-2.0-flash。免费档有限速，个人聊天一般够。

聚合平台OpenRouter

openrouter.ai 注册拿 Key，端点 https://openrouter.ai/api/v1。模型列表里名字带 :free 的不花钱，一个 Key 能试几十家的模型，适合"都想尝尝"的人。

便宜省事DeepSeek（桌宠默认）

platform.deepseek.com 注册充值（10 块钱能用很久），端点 https://api.deepseek.com/v1，模型 deepseek-chat。桌宠出厂就配好这个端点，你只要填 Key。

五、填完之后

  1. 设置页保存，桌宠气泡会提示连接结果
  2. 发一句话试试——苏苏洛回你，就成了
  3. 开了语音的话，她会读出来
连不上怎么办？按顺序查：① Key 有没有复制全（前后别带空格）② 端点结尾要不要 /v1（OpenAI 兼容一般要，桌宠会自动补）③ 账户里还有没有额度 ④ 看日志 logs/tts.log 里的报错。

六、安全三句话

① API Key 等于钱包，别发群里、别贴网上；

② 用免费额度也开着「用完即停」或限额，防超额；

③ 桌宠的 Key 存在本机加密存储（DPAPI），不随发布包外泄，放心。
