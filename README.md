# 苏苏洛桌宠 · 2.5 正式版（SuzuranPet）

Q 版狐狸医师桌宠：悬浮在桌面上，日常聊天陪伴。**免安装、绿色版**——解压后双击 exe 即用，无需 Node / Python（不开语音时）。

2.0 是 1.1 的一次大版本升级：日语语音质量全面治理、桌面行走焕新、新增日程提醒与新手教程、密钥安全加固，并配套了「音色训练懒人包」（含训练好的苏苏洛音色，免训练直接体验）。

感谢 [High-Logic/Genie](https://github.com/High-Logic/Genie/tree/master) 的开源。

## ✨ 2.5 更新亮点（相比 2.0）

- **语音开箱即用**：中文（GenieTTS 克隆音色）+ 日语（GPT-SoVITS）引擎与苏苏洛训练成品随包自带，解压就能说话，不用装环境
- **📖 内置文档中心**：托盘右键直接看新手教程、语音指南、API 接入指南（含学生免费额度攻略）
- **🎭 Live2D 角色（实验）**：第四种渲染模式，支持 Live2D 模型（内置示例，自定义模型放进 `assets/live2d/` 即可）
- **皮肤全量内置**：苏苏洛全形态 + 迷迭香、W、维什戴尔等 38 款
- **更安全**：DLL 完整性自检、数字签名、两轮 VM 隔离安全测试；发布包无任何个人残留

## ✨ 2.0 更新亮点（相比 1.1）

### 🎙️ 语音（重点大改）
- **日语语音质量全面治理**：修复句间停顿未按 16bit 帧对齐导致的整段电音、拼接边界咔哒爆音、8kHz 窄带啸叫、播放端三处杂音；保留句尾衰减、真人节奏停顿，语调更自然
- **合成稳定性**：串行队列 + 重试退避 + 崩溃当场自愈重试本句 + 播放互斥；GSV 弃用半精度（fp16 偶发数值不稳定），改全精度
- **GSV 引擎可靠性**：设备自动检测（有 N 卡用 CUDA、否则 CPU）、启动预热、单飞防重入、连续失败熔断回退中文、引擎死亡自动清理挂死进程
- **Genie 引擎防劣化**：参考音频切换去重（LAST_REF_AUDIO）、mkstemp 安全修复
- **TTS 端点安全**：本地 TTS 服务器只允许 loopback，远端需显式 allowRemote + HTTPS

## 快速开始

> 🐣 **完全新手？** 请看图文版手把手教程：[`docs/快速开始.md`](docs/快速开始.md)（API Key 去哪领、怎么填、常见故障怎么办，小学生也能看懂）。

> 📚 **新手全家桶（说人话版）**：零基础也能看懂的 7 篇教程（安装/记忆/换皮/日语语音/行走/安全/FAQ）→ [`docs/TUTORIALS/README.md`](docs/TUTORIALS/README.md)

> 🐱 **想给她换个人设？** 有一份填了就能用的人设模板：[`docs/persona-template.md`](docs/persona-template.md)（占位符自动替换，附成品示例，复制进设置页→人设即可）。

1. 解压整个文件夹（建议放在桌面或喜欢的位置）
2. 双击 `苏苏洛桌宠.exe`
3. 首次启动会自动弹出「⚙️ 设置」：
   - **① 聊天 API**：选服务商（DeepSeek / Kimi / OpenAI / GLM / Qwen / 本地 Ollama…）→ 填 API Key →「测试连接」→「保存」
   - 把「桌宠对你的称呼」改成你的名字（人设会自动用这个名字）
4. 单击小狐狸 → 输入框 → 回车，开始聊天

## 换人设

- 托盘图标右键 →「⚙️ 设置」→「② 人设」直接编辑，保存立即生效
- 人设文本里 `{{userName}}` 会自动替换成你在设置里填的称呼
- 「恢复默认人设」可随时还原

## 语音（可选）

默认关闭、零安装。想开语音：
托盘右键 →「🎤 语音部署与训练」打开指南文件夹，四种方案任选：

1. **系统自带语音**：零配置
2. **edge-tts 云端**：装 Python 后 `pip install edge-tts`
3. **本地克隆音色（Genie / GPT-SoVITS）**：按指南部署后，直接在程序里「🎙️ 音色克隆与训练」窗口选音频 → 试听 → 一键应用，即可克隆出任意音色（含苏苏洛）
4. **百炼 CosyVoice**：填 API Key + 音色 ID

### 日语语音模式（界面中文、说话日语）

想让桌宠**说日语**（用苏苏洛等日语微调音色）：设置 → 语音 → 勾选「🗣 日语语音模式」。

- 开启后：气泡文字仍是中文，回复会先翻译成日语，再由本地 GPT-SoVITS 用日语音色合成播放。
- 需要本地部署 GPT-SoVITS v2ProPlus 并配置 `config.json` 的 `ttsGsv` 段（路径、训练好的权重、日语参考音频）。
- 完整步骤见「语音部署与训练指南」文件夹里的《日语模式部署指南.md》；日语服务不可用时自动回退中文，不影响使用。

## 换皮肤 & 自定义情绪

- 托盘右键 →「🎨 表情管理」：每个情绪（开心/思考/生气/睡觉…）单独一个格子，点「选择 GIF」填入自己的表情，随时可「恢复默认」
- **自定义情绪**：没有想要的？在表情管理里自己加（≤5 个字，最多 30 个，如「摸鱼」「干饭」），再给它选个 GIF
- AI 会在回复时自动理解对话、选择最贴切的情绪来表现（比如你喊困，她就用「睡觉」表情）

## Spine 小人 & 桌面行走

- **切换小人模式**：托盘 → 设置 → ④其他 → 渲染模式，选「Spine 小人模型」保存即可（内置苏苏洛基建小人，动画语义与游戏一致：Relax 放松待机 / Move 走动 / Interact 点击互动 / Sleep 睡觉）
- **桌面行走**：设置里勾选「🚶 桌面行走」（或托盘菜单开关）。小人以**任务栏上沿为地面**左右散步、走走停停（明日方舟基建节奏），偶尔**一步跳到桌面上的程序窗口顶上坐着歇一会**再跳回来；走路朝向跟随实际移动方向；拖拽她时暂停，单击她播放互动动作
- **多皮肤切换**：托盘「🧩 人物」菜单一键切换（角色 → 形态 → 皮肤三级）；在 `resources\app\renderer\spine\user\` 下每个皮肤建一个文件夹放入模型文件即可被识别（如 `summer/`、`winter/`）；文件名避免 `#` 等特殊符号
- **懒人换自己的小人**：把任意 Spine 模型的 `xxx.atlas` + `xxx.skel`（或 `.json`）+ `xxx.png` 放进上述某个文件夹，重启桌宠即出现在皮肤菜单，无需任何配置；删除即恢复内置苏苏洛
- 经典 GIF 表情模式不支持桌面行走（GIF 是静态贴图，没有骨骼动画）

## 常见问题

- **双击没反应 / SmartScreen 拦截**：未签名程序首次运行点「更多信息」→「仍要运行」
- **提示没配 API Key**：托盘 → 设置 → 填 Key → 测试连接
- **聊天没反应**：看是不是输入框没打开（单击小狐狸）；或 API 欠费/模型名不对
- **想开任务模式（/zcode 前缀操控电脑）**：需要另装 ZCode，然后在 `config.json` 里把 `zcodeEnabled` 改为 `true` 并填 `zcodeCli` 路径（默认关闭）
