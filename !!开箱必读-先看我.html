🎁 恭喜拿到苏苏洛！

这份说明 2 分钟看完，看完就能玩。看不懂的地方不用研究，照着做就行。

三步开始

1解压，然后双击「苏苏洛桌宠 2.5 正式版.exe」

第一次启动如果 Windows 弹蓝色警告「已保护你的电脑」，点 更多信息 → 仍要运行（我们的程序没花钱买微软的信任章，不是病毒）。

杀毒软件如果报警，选「信任」或加入白名单。

2弹出《使用条款》→ 往下拉 → 点「同意」

同意之后桌宠就会出现在你的桌面上啦。右下角任务栏里有个小图标，右键它就是全部菜单。

3填一个 Key，她才能和你聊天

右键托盘图标 → 设置 → 聊天设置里填 API Key。没有 Key？看文档中心（右键托盘 → 📖 文档中心）里的《API 接入指南》，里面有免费白嫖渠道（学生还能领阿里云 300 元券），5 分钟能搞定。

填完发一句话，她回你，就成了 ✅

关于说话（语音）

🗣 她出厂就带着说话能力（中文 + 日语都是真人音色）。

· 第一次说话前要等 1~2 分钟（引擎在后台加载，不是卡住了），之后反应就快了

· 想让她说日语：右键托盘 → 「🗣 日语模式」打开即可

· 说话没声音？右键托盘看「🔊 语音」是否开着，再检查系统音量

我的电脑配置行不行？

你想干什么需要什么
聊天（打字）什么电脑都行，不需要显卡（AI 在云端）
中文语音普通电脑就行，不需要显卡（第一次加载稍慢）
日语语音建议有 NVIDIA 显卡（GTX 1060 以上体验好）；没有也能开，但说得非常慢，建议不开
内存建议 8GB 以上
硬盘整个包解压后约 16GB，别放在快满的盘里

再多玩两天之后

· 换形象：设置 → 渲染模式，除了经典表情还有 Spine 小人、2.5D 角色、Live2D 角色（自带示例模型，自己的模型放进 assets/live2d/ 文件夹就能选）

· 深色模式：设置 → 主题颜色，可以自动（晚上 7 点后变深色）、跟随系统、或手动定

· 对她不满意？气泡右下角有 ↻ 重新生成一个版本，‹ › 来回切换对比

· 让她记住事：直接说"记住我喜欢草莓"，她就记住了（设置页里能看到和删除）

· 这些在 📖 文档中心（右键托盘）都有详细说明

遇到问题怎么办

① 先看内置文档：右键托盘 → 📖 文档中心 → 里面的《常见问题》《API 接入指南》覆盖了大部分情况。

② 角色消失了 / 点不动 / 花屏：试试右键托盘 → 退出，重新双击 exe。还不行就把日志发给作者：你的用户目录\AppData\Roaming\苏苏洛桌宠 1.1 正式版\logs\tts.log（找不到就整个 logs 文件夹压缩发过去）。

③ 换电脑 / 换文件夹：整个文件夹拷走就能用，聊天记录和设置在 C:\Users\你\AppData\Roaming\苏苏洛桌宠 1.1 正式版 里。

千万别做的事：不要把 API Key 发给别人；不要删除 engines 文件夹（删了就不能说话了）；不要把整个包放进 C 盘快满的盘。
