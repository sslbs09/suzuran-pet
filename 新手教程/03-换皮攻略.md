# 03 · 换皮：表情 / Spine 模型 / 2.5D 皮肤

桌宠有三种"皮肤"，可以混着用（同一时间用一种）：

## ① GIF 表情（最简单，小白也能加）
表情就是文件夹里的一张张动图。位置：`...\resources\app\renderer\sprites\user\`。
**怎么加**：
1. 设置 → 其他 → 打开表情管理（或用托盘 → 表情）。
2. 选一个情绪（如"开心"），点"选择 GIF"，挑你的动图即可。

- 每个情绪一张图；没有素材的情绪会自动用回默认。
- 想恢复默认？点"重置"就行（原始表情备份在 `sprites/default/`，不会丢）。

## ② Spine 模型（游戏级可动，进阶）
Spine = 骨骼动画（会眨眼、摆手那种）。模型放 `...\spine\user\` 下，一个角色一个文件夹（.atlas + .skel + 图集）。
- 放好后设置 → 渲染模式选 Spine → 选模型。
- 它走路会用 Sit/Move/Relax 三种动画；模型没有的动画会自动回退（不会白屏）。

## ③ PSD 分层皮肤（自己动手调，神器）
设置/托盘 → **PSD 角色工具**：拖入一张分层的 .psd 就能：
- **逐层编辑**：点选图层 → 隐藏/复制/删除/缩放（按内容中心），误操作可 **Ctrl+Z 撤销**。
- 预览 2.5D 动态效果（自动眨眼/呼吸/视线跟随）→ 满意后点"应用到桌宠"。
- 隐藏的图层不会进桌宠；改过的图层会跟着一起应用（不再需要重新导出整张图）。

> 黑话翻译：psd = 很多张图叠起来的一个文件，像洋葱；"图层"就是其中一层。

## 换完皮没变化？
- 改的是 **resources\app**（正式版内部）→ 改完**重启桌宠**。
- 检查路径有没有放对（大小写、文件夹名）。
