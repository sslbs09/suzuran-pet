# 02 · 教它记住你（称呼 / 小事 / 羁绊）

## 它靠"聊天里的小纸条"记住你
苏苏洛不会偷听，只会在**你主动说**的时候记下几类事：

| 你说的话 | 它会记住 |
|---|---|
| "以后**叫我阿米娅**就好" | 你的称呼（它真的会这么叫你） |
| "我**生日是3月25日**" | 你的生日（当天它会主动祝贺） |
| "我最**喜欢喝奶茶**" | 你的喜好 |
| "我最近**感冒**了 / **在准备考试**" | 你的身体/安排（它会记得关心、给你打气） |
| "明天**下午3点记得提醒我**写方案" | 一条提醒（到点语音提醒你） |

> 原理一句话：它从你话里"抽小纸条"，存进本地的小本本（memory.json），聊天时夹进它的"人设说明"里——所以它说话时会想起这些事。

## 想让它忘记？去设置里删
设置 → 🧠 **记忆管理**：
- 能看它**记住了多少条**，还能把某一条单独"撕掉"。
- 记忆是**加密存本地**的（存在 Windows 系统的加密保险柜里，只有你这个电脑用户能打开，别人偷不走；详见教程 06）。

## 羁绊（它越来越离不开你）
它有个小账本（bond.json）：你**摸它头**、和它**聊天**都会加经验。
- 等级会涨（Lv.1→Lv.10…），升级时它会弹一句"羁绊升级"。
- 人设里会带上"已陪伴 X 天 · 羁绊 Lv.X"，聊天气氛会跟着变熟。

## 小白提醒
- ❌ 想让它记住事但**一直没聊过** → 先打招呼聊天，再告诉它。
- ✅ 想测试它记没记住 → 问它"你还记得我喜欢什么吗？"
