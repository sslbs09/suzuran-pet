# 07 · 常见问题 FAQ（想到哪问哪）

## 桌宠不动了 / 卡住了
- 先确认它是不是**睡着了**：5 分钟没互动它会闭眼静立，点它/说话就醒。
- 关掉"实验性"里的开关（桌面全域行走）再试。
- 看日志 `logs\tts.log` 里有没有"状态告警"行（90 秒无变化会写），有就发我。

## 没声音
1. 设置 → ③语音 → 总开关开了吗？
2. 选了日语模式但没装声库？先关日语模式试试系统语音/edge。
3. 声库（9880）活着吗？（声库控制台看）

## 声音是中文 / 不像苏苏洛
- 中文：没勾"日语语音模式"。
- 不像：参考音频没被用上——检查情绪音色试听；或该情绪被"音色启用"关掉了。

## 弹了个"JavaScript 错误"框
这是**旧版本**的毛病（主进程异常没兜底弹冻结框），v2.6 之后已修复：异常只记日志不弹窗。
如果还看到，说明你跑的不是最新 main.js——重新覆盖并重启。

## 黑屏 / 画面闪
- 试设置 → 实验性 → **🖥 软件渲染**（无独显/驱动异常时用 CPU 渲染，重启生效）——变慢但更稳。
- 也建议更新显卡驱动。

## CPU 占用高
- 全局鼠标跟踪 / 逗猫棒是持续读鼠标的，不用就关（设置 → 实验性）。

## 想让它换称呼 / 忘记事
- 称呼：直接说"以后叫我 XX"；记忆管理里可删单条（见教程 02）。

## 加表情/换皮肤没生效
- 路径对不对：`resources\app\renderer\sprites\user\`（GIF）、`spine\user\`（Spine）。
- 改完**重启桌宠**。

## 怎么卸载干净
1. 退出桌宠（托盘右键 → 退出）。
2. 删掉桌宠文件夹（可保留），再删 `AppData\Roaming\苏苏洛桌宠 1.1 正式版`。
3. 想彻底不留痕：任务管理器结束相关进程后删（正常退出即可，无驻留服务）。

## 看到"上一句还没说完"/发消息没反应
这是**消息防抖**：它正在说话/生成时你连发，会在当前回合结束后自动补发（v2.6 特性，不再吞消息）。
如果一直没补发，检查 AI 服务配置（教程 04 那条线）。
