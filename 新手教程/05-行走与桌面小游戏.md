# 05 · 行走与桌面小游戏

## 先开行走
设置 → 渲染模式选 **Spine**（行走只在 Spine 模式生效）→ 其他/托盘打开"行走"。

它会：在任务栏上**散步 → 坐下休息 → 偶尔跳上窗口顶/桌面图标坐一会儿**，循环不断。
时长节奏可以在设置里调（散步/坐下的秒数上限）。

## 让它走得更野：桌面全域行走（实验）
设置 → 实验性功能 → **🌍 桌面全域行走**（默认关）：
- 开：它会从主屏一路走到另一个屏幕，跨屏自动按那块屏的地面贴地。
- 关：只在当前屏幕散步（更"乖"）。

> 注意：多显示器依然建议先开"实验性"观察一两天，满意再放心用。

## 和它玩
| 动作 | 会发生什么 |
|---|---|
| **点它一下**（摸头） | 它会说句撒娇台词，羁绊 +1 |
| **按住拖拽** | 拖到哪放哪；贴近任务栏会自动坐下 |
| **甩出去**（快速拖动后松手） | 它会"飞"出去、落地弹跳，还会抱怨你（人性化台词） |
| 长时间不碰它（5 分钟） | 它**睡着了**（闭眼静立）——这不是卡住，点它/跟它说话就醒 |

## 两个"看起来像坏了"其实是设计的
1. **站着不动 5 分钟后闭眼** = 睡着（见上）。
2. **卡在屏幕边上来回走**的一小会儿 = 它在边缘"折返"，正常。

## 行走出问题？
设置 → 实验性提过的开关都先关掉试试；还不行就翻日志（见教程 06 的日志路径）找"状态"行，
或直接告诉我现象，我帮你从日志定位。
