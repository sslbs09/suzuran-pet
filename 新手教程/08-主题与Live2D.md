# 主题与 Live2D

这篇讲两个"让她更好看"的功能：深色模式和 Live2D 角色。

## 主题颜色（深色模式）

右键托盘 → 设置 → 顶部「🎨 主题颜色」：

- **自动**：晚上 7 点到早上 6 点自动变深色，白天浅色，不用管
- **跟随系统**：Windows 开了深色模式她就跟着深
- **浅色 / 深色**：自己手动定

切换马上生效，桌宠的对话框、设置页、文档中心会一起变。

## Live2D 角色（实验功能）

渲染模式支持第四种：**Live2D 角色**。

- **切换**：设置 → 渲染模式 → 「Live2D 角色（实验，内置示例模型）」，会显示一个内置的示例少女
- **换自己的模型**：把模型文件夹（里面要有 `.model3.json` 文件）放进
  `C:\Users\你\AppData\Roaming\苏苏洛桌宠 1.1 正式版\assets\live2d\`
  然后打开设置页，Live2D 区块里就能选到；旁边还有「角色大小」滑条可调
- **互动**：点击她会做动作，聊天时情绪不同动作也不同，拖拽扔出去她会有反应
- **气泡右下角的 ‹ n/m ↻**：她回复后点 ↻ 能让她换种说法，‹ › 在多个版本间来回切换

> 注意：Live2D 是实验功能，模型格式需要 Cubism 3/4/5（带 `.model3.json` 的那种）。
