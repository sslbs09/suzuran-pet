# Official Cubism Web R5 source boundary

The files under `src/` are the bounded sample adapter used by this product
runtime. They retain the copyright and license header from the official
Live2D Cubism Web R5 sample. The upstream Open Software license is:

https://www.live2d.com/eula/live2d-open-software-license-agreement_en.html

The Cubism SDK Framework, Cubism Core, Haru model, textures, and generated
bundle remain explicit local inputs. They are never copied into this branch.
